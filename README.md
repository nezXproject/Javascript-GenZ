## 📖 Tentang Proyek

**Javascript-GenZ** adalah sebuah proyek eksperimental dan interpretasi baru terhadap JavaScript, yang dirancang untuk menangkap semangat kreativitas, kecepatan, dan ekspresi dari generasi digital native. Proyek ini bertujuan untuk mengeksplorasi bagaimana sintaks dan paradigma pemrograman dapat berevolusi, menciptakan pengalaman menulis kode yang lebih intuitif, menyenangkan, dan relevan dengan gaya komunikasi modern.

Proyek ini adalah bukti konsep yang menunjukkan bahwa bahasa pemrograman dapat menjadi medium yang hidup, adaptif, dan mencerminkan budaya pembuatnya.

## ✨ Fitur Utama

*   **Sintaks Ekspresif:** Nikmati cara baru dalam menulis logika yang terasa lebih alami dan langsung.
*   **Filosofi GenZ:** Dibangun di atas prinsip kecepatan, kolaborasi, dan kebebasan berekspresi.
*   **Terbuka untuk Eksplorasi:** Proyek ini adalah kanvas bagi para kontributor untuk bereksperimen dengan desain bahasa.
*   **Berbasis JavaScript:** Dibangun di atas ekosistem JavaScript yang kuat dan dikenal luas.

## 🛠️ Memulai

### Prasyarat

Pastikan Anda telah menginstal [Node.js](https://nodejs.org/) (versi terbaru direkomendasikan) di sistem Anda.

### Instalasi

1.  **Clone repositori:**
    ```bash
    git clone https://github.com/nezXproject/Javascript-GenZ.git
    cd Javascript-GenZ
    ```

2.  **Instal dependensi (jika ada):**
    ```bash
    npm install
    ```
    *(Catatan: Proyek ini masih dalam tahap awal, struktur file dan dependensi akan terus berkembang)*

### Contoh Penggunaan

Lihat direktori `javaz-lang/` untuk contoh-contoh kode, seperti file `skena.jz`. Jalankan interpreter atau compiler (sesuai dengan perkembangan proyek) untuk melihat hasilnya.
